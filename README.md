# Flint & Copper Plumbing & Heating (example site)

A demo plumber website by [Running Ape](https://runningape.org) for a **made-up** Norfolk business.
Live at https://flintandcopper.runningape.org (a Cloudflare Worker serving static files from `public/`, set in `wrangler.jsonc`; no build step). Edit `public/index.html`.

- Demo phone number 01632 960 418 is from Ofcom's range reserved for TV and drama.
- The forms don't send anywhere. Review cards are placeholders (no made-up reviews).
- `noindex` so it stays out of Google. Photos are hotlinked from Unsplash.
